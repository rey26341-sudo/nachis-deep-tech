# Dual-Use Telemetry Normalization Engine (Pre-Seed Prototype)

> **Status:** Pre-Seed Benchmark / Proof of Concept  
> **Target Application:** Dual-use telemetry data normalization, schema validation, and cryptographic audit hashing for connected hardware (aerospace & logistics).

## Quickstart (Ubuntu / Docker)

Build and execute the test pipeline using Docker:

```bash
docker build -t telemetry-proof .
docker run --rm telemetry-proof
```
